# ESP-018 实现温控配置校验与持久化

- 里程碑：M5
- 状态：进行中（NVS 适配与未知保存恢复主机测试通过，待设备编译和实物验收）
- 范围：必需 · 完整入门项目
- 依赖：[ESP-006](ESP-006.md)、[ESP-008](ESP-008.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

可靠保存阈值且不恢复开启状态。

## 实现范围

- 实现 ConfigStore，校验 0～60℃且 offThresholdC 至少比 onThresholdC 低 1℃。
- 以完整配置和格式版本保存；仅显式且有变化的修改触发写入。
- 缺失、损坏或不支持的格式回退 30／28 并记录诊断。
- 明确写入失败保留旧的运行配置和旧可恢复配置；结果未知时保留运行阈值、暂停后续配置保存，重启读取实际保存值。不持久化 mode 或 fanOutputOn。

## 交付物

- 配置存储模块、故障注入测试、默认值与版本说明。

## 验收步骤与预期

- [ ] 修改后重启阈值保留，但模式仍为手动且输出关闭。
- [x] 非法配置被拒绝，两阈值不会部分更新；相同配置不重复写（主机测试）。
- [x] 模拟损坏配置回退默认值，模拟存储失败时旧配置仍可用。

## 前提与限制

存储具体实现随已选工具链确认，不增加数据库服务。
