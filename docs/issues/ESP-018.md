# ESP-018 实现温控配置校验与持久化

## 目标

可靠保存阈值且不恢复开启状态。

## 实现范围

- 实现 ConfigStore，校验 0～60℃且 offThresholdC 至少比 onThresholdC 低 1℃。
- 以完整配置和格式版本保存；仅显式且有变化的修改触发写入。
- 缺失、损坏或不支持的格式回退 30／28 并记录诊断。
- 写入失败保留旧的运行配置和旧可恢复配置，不持久化 mode 或 fanOutputOn。

## 交付物

- 配置存储模块、故障注入测试、默认值与版本说明。

## 验收步骤与预期

- [ ] 修改后重启阈值保留，但模式仍为手动且输出关闭。
- [ ] 非法配置被拒绝，两阈值不会部分更新；相同配置不重复写。
- [ ] 模拟损坏配置回退默认值，模拟存储失败时旧配置仍可用。

## 前提与限制

存储具体实现随已选工具链确认，不增加数据库服务。
