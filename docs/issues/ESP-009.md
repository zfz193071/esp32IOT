# ESP-009 识别红外接收硬件与遥控编码

- 里程碑：M3
- 状态：待办
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-001](ESP-001.md)、[ESP-003](ESP-003.md)、[ESP-004](ESP-004.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

获得可靠的遥控器映射依据。

## 实现范围

- 选择与实物兼容的红外库并锁定版本。
- 实现只记录必要编码的诊断模式，识别开／关候选按键及重复帧。
- 记录协议、地址、命令码、长按行为及接收器接线。

## 交付物

- 红外诊断程序、遥控按键映射表、依赖版本记录。

## 验收步骤与预期

- [ ] 每个候选键短按多次，稳定识别为同一按键。
- [ ] 长按与未知按键行为有记录，不将重复帧当作新的未知控制码。

## 前提与限制

缺少接收器或无法确认供电时标记阻塞。
