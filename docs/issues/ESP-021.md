# ESP-021 完成温控实物联合验收

- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

验证温控在真实设备上与本地及网页控制协同。

## 实现范围

- 用温和温度变化或适合当前环境的合法阈值演示自动开关与回差。
- 验证自动中手动接管、配置更新、温度不可用、断网、重启与恢复。
- 保存实际采样周期、故障发现时延和配置值，不将设计值写成实测结果。

## 交付物

- M5 实物验收报告与温控演示步骤。

## 验收步骤与预期

- [ ] 阈值附近不出现无规则频繁启停，行为满足 019 状态规则。
- [ ] 断网期间温控继续工作，按键／红外仍可接管。
- [ ] 温度故障退出自动；样本恢复后不会自动恢复 auto。
- [ ] 重启阈值保留且手动关闭。

## 前提与限制

断线检查遵循已确认接线规范，不要求带电随意拔插。
