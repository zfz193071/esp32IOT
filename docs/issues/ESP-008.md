# ESP-008 装配主循环、状态 LED 与串口诊断

- 状态：待办
- 范围：必需 · 局域网 MVP

## 目标

完成可独立运行的按键风扇。

## 实现范围

- 装配输入、控制器、FanOutput 和 StatusIndicator；LED 读取统一快照。
- 建立非阻塞调度顺序：更新传感器健康、接收命令、计算规则、提交输出。
- 记录启动、命令来源、模式、输出变化和故障；按变化或限频输出日志。
- 为后续网络和采样安排有限处理预算，避免输入洪泛长期占用循环。

## 交付物

- 主循环、状态指示、串口诊断与本地风扇操作说明。

## 验收步骤与预期

- [ ] 按键开关风扇时 LED 与快照一致。
- [ ] 反复操作和持续按住时仍可响应后续操作，日志不逐循环刷屏。
- [ ] 断开电脑的调试终端后，保持合规供电即可独立本地控制。

## 前提与限制

数码管和蜂鸣器不在此单范围。
