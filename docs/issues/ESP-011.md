## 目标

联网失败也能继续本地控制。

## 实现范围

- 使用私有配置提供 Wi-Fi 凭据，输出局域网 IP 和连接状态。
- 实现非阻塞连接与限频重连，不做配网门户。
- 将 wifiConnected 纳入快照，不改变模式和电机输出。

## 交付物

- NetworkService、凭据样例、重连与 IP 诊断说明。

## 验收步骤与预期

- [ ] 正确凭据可连接并输出 IP，密码不进入日志。
- [ ] 使用错误凭据或关闭路由器时按键持续可用；网络恢复后自动重连。
- [x] 断网期间现有输出保持，网络变化不会触发电机开关（模拟驱动与真实控制器主机验证，待实物联调）。
