## 目标

确认设备在异常和持续使用中保持约定行为。

## 实现范围

- 检查断网与重连、传感器故障、复位与烧录、连续开关、快速输入和重复 HTTP 请求。
- 进行至少 2 小时连续运行及 20 次开关验收，记录重启原因、采样健康、响应情况和供电现象。
- 比较压力前后采样和本地响应，确保没有持续饿死；根据结果修复调度或限频并复验。

## 交付物

- 异常与稳定性报告、缺陷记录及复验结果。

## 验收步骤与预期

- [ ] 无非预期重启或误开启，持续输入下本地控制与采样仍推进。
- [ ] 断网不阻塞本地／自动控制，温度故障行为与架构一致。
- [ ] 连续运行结果有开始结束时间、固件版本、接线配置和观察记录；未实测项目不能勾选完成。

## 前提与限制

时长与次数是本工单新增验收基线，不是已有性能数据。
