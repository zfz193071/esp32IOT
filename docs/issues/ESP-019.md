# ESP-019 实现自动温控与故障状态转换

- 里程碑：M5
- 状态：进行中（自动规则主机测试通过，待采集与设备联调）

- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

按回差规则自动开关，并支持手动接管。

## 实现范围

- 实现进入自动模式的健康与阈值检查；进入时从关闭基准计算。
- 实现温度 ≥ on 开启、≤ off 关闭、中间区间保持输出。
- 手动 SetPower 覆盖自动；切换 manual 保持输出。
- 自动中温度失效立即关闭、转手动并置故障；温度恢复清除故障但不恢复自动。
- 按主循环约定先更新健康再接收命令；新阈值生效后自动模式立即重算。

## 交付物

- 自动控制逻辑和完整状态转换测试。

## 验收步骤与预期

- [x] 默认阈值下 29→30→29→28℃的输出为关→开→开→关（注入温度主机验证）。
- [x] 进入自动模式时温度 29℃，即使此前手动开启也变为关闭（主机验证）。
- [x] 无效或过期温度无法进入自动，运行中失效关闭并退出；恢复不会自行开启自动（主机验证）。
- [x] 自动中手动开关立即接管；切回 manual 不额外改变输出（主机验证）。

## 前提与限制

测试用注入温度验证边界，实物温度变化验证采集整合。
