# ESP-014 实现随固件发布的手机控制网页

- 里程碑：M4
- 状态：进行中（页面与模拟接口验证通过，待固件嵌入和设备联调）
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-012](ESP-012.md)、[ESP-013](ESP-013.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

手机无需安装 App 即可控制风扇。

## 实现范围

- 使用原生 HTML/CSS/JavaScript 提供开／关、模式、连接状态与控制输出显示。
- 通过 GET / 从 ESP32 提供页面，静态资源构建时嵌入固件，不依赖外部 CDN。
- 每秒读取状态；无温度能力时明确显示不可用，自动模式不可误导为已启用。
- 所有文案使用控制输出语义，并说明切换手动保持输出。

## 交付物

- firmware/web 页面、资源嵌入构建步骤、手机使用说明。

## 验收步骤与预期

- [ ] 同一 Wi-Fi 手机访问设备 IP 可加载并操作，PC 服务器无需运行。
- [ ] 按实体键或红外后页面下一次成功同步显示正确输出。
- [x] 小屏上控制按钮与状态可见，页面无外部资源依赖（390×844 Chrome 模拟视口）。

## 前提与限制

复杂响应时序在 015 完成。
