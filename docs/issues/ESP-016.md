## 目标

交付首个可用的手机／按键／红外控制版本。

## 实现范围

- 按统一脚本验收三种入口、状态同步、重复命令、请求异常、断网恢复和重启关闭。
- 验证未安装温度模块时手动功能完整，自动模式被明确拒绝。
- 保存构建版本、硬件配置、操作步骤和结果，记录缺陷并修复后复验。

## 交付物

- M4 验收报告、可重建的固件版本信息、演示步骤。

## 验收步骤与预期

- [ ] 三种入口交替操作，每次成功查询状态与输出一致。
- [ ] 断网时按键和红外仍可用；恢复连接后网页反映当前状态。
- [ ] 断电重启后为手动关闭，无历史命令自动重放。

## 前提与限制

验收记录必须来自实际设备；模拟通过单独标注。

## 完成记录

2026-10-28：在 `firmware/test/AppLoopTest.cpp` 增加 M4 软件联合场景，使用真实 C++ 控制器、网络调度、红外映射和 API 处理，模拟网页→按键→红外接管、状态查询、断网时拒绝旧地址写入、本地输入继续工作、限频重连后同步离线操作、无传感器时拒绝自动模式、重复显式关闭不再写输出，以及以新 bootId 重建 AppLoop 后手动关闭。测试入口为 `sh firmware/test/run-host-tests.sh`。
