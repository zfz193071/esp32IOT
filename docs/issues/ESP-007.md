# ESP-007 实现电机输出适配与启动关闭

- 里程碑：M2
- 状态：待办
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-002](ESP-002.md)、[ESP-003](ESP-003.md)、[ESP-004](ESP-004.md)、[ESP-005](ESP-005.md)、[ESP-006](ESP-006.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

将控制器输出可靠地映射到已确认的电机驱动。

## 实现范围

- 实现 FanOutput，封装有效电平和关闭初始化。
- 先在电机断开条件检查输出，再按已确认供电方案接入驱动及电机。
- 确保网络及其他耗时初始化前输出已处于关闭状态；只有控制器能提交输出。

## 交付物

- 电机驱动适配器、实物接线记录、启动／复位测试结果。

## 验收步骤与预期

- [ ] 开机、复位和烧录过程保持预期关闭状态。
- [ ] 通过控制器交替开关 20 次，电机无误动作，开发板无异常重启。
- [ ] 输出状态按控制信号命名，不宣称检测到了实际转速。

## 前提与限制

实物驱动和供电未确认时，禁止以模拟测试替代硬件验收。
