## 目标

提供可用于控制的温度样本与有效性信息。

## 实现范围

- 依据实物确认温度库并锁定版本，按约 1 秒周期请求转换和检查结果。
- 识别断线、校验错误、器件异常读数和未完成转换；无效时输出 null。
- 跟踪最近有效采样时间，超过 5 秒无有效样本进入 stale；时间计算支持计时器回绕。
- 维护 initializing/ok/invalid/stale，传感器模块不直接控制风扇。

## 交付物

- TemperatureService、接线与采样记录、健康状态测试。

## 验收步骤与预期

- [ ] 正常温度可连续读取，转换等待期间按键和网络仍可响应。
- [x] 模拟无效读数和采样停滞，状态分别正确进入 invalid 或 stale（主机验证）。
- [x] 无样本时 sampleAgeMs 为 null；恢复采样后健康状态回到 ok（调度与既有序列化主机测试）。

## 前提与限制

实际断线测试按硬件说明操作；时钟边界可通过可控时钟测试。
