# ESP-002 确认电机驱动、供电与上电关闭方案

- 里程碑：M0
- 状态：待办
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-001](ESP-001.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

在连接电机前确定匹配的低压驱动和供电方案。

## 实现范围

- 核对电机额定电压及启动／堵转电流资料、驱动额定能力、保护措施与电源能力。
- 确认底板是否已有可用驱动，画出电源、驱动、电机和控制信号路径。
- 明确复位、烧录、引脚未初始化时的关闭电平及必要硬件措施；不靠初始化代码保证全过程关闭。
- 若现有配件不足，记录具体缺项和规格要求，未补齐前阻塞接电机任务；不自动采购。

## 交付物

- docs/hardware.md 中的供电与驱动方案、接线示意、缺项表。

## 验收步骤与预期

- [ ] 方案中的每个供电和控制接口有明确电压与用途。
- [ ] 确认 GPIO 不直接承担电机负载，复位／烧录阶段不会因悬空输入误启动。
- [ ] 资料不足时记录未解决项，不用危险的堵转实验代替额定资料。

## 前提与限制

依赖驱动及电机参数，未确认之前不能连接电机。
