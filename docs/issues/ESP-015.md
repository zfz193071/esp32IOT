# ESP-015 实现网页请求串行与异常恢复

- 里程碑：M4
- 状态：进行中（请求协调与模拟验证通过，待设备联合测试）
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-014](ESP-014.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

防止超时或乱序响应误导用户。

## 实现范围

- 每次最多一个写请求在途，禁止乐观显示写成功。
- 结合 bootId/revision 和请求生命周期丢弃旧响应；检测重启后使旧请求失效并重新读取。
- 写请求超时提示结果未知，恢复连接后查询状态，不自动重放旧命令。
- 断网或读取失败显示失联及最后同步信息，避免将旧值呈现为实时状态。

## 交付物

- 页面请求协调逻辑、可复现的乱序／超时测试方法。

## 验收步骤与预期

- [x] 快速连续点击不会并行提交多条写命令（主机模拟）。
- [x] 模拟旧轮询晚于新写响应到达，页面不退回旧状态。
- [ ] 请求期间重启设备，旧 bootId 响应不会覆盖新启动状态（模拟通过，待真实设备）。
- [x] 模拟写入已生效但响应丢失，页面先显示未知再通过查询恢复，不自动再发命令。

## 前提与限制

可使用模拟 HTTP 响应验证时序，再做设备联合测试。
