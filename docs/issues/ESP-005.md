# ESP-005 实现按键消抖与 LED 入门实验

- 里程碑：M1
- 状态：进行中（独立按键／LED 实验已装配，待接线确认与实物验证）
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-004](ESP-004.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

在不接电机时验证基础 GPIO 和事件处理。

## 实现范围

- 通过 BoardProfile 读取按键和驱动 LED，定义按下事件。
- 实现非阻塞消抖，持续按住不重复产生切换事件。
- 记录实测消抖参数和串口观察方式；实验代码与正式业务装配入口分开。

## 交付物

- 按键／LED 实验、消抖输入适配器、实测记录。

## 验收步骤与预期

- [ ] 连续按下释放 20 次，LED 每次仅切换一次。
- [ ] 持续按住 3 秒只触发一次；松开后再次按下可正常触发。
- [ ] 重启后 GPIO 和 LED 行为与接线说明一致。

## 前提与限制

次数和时长为工单验收标准，尚无实测结果。
