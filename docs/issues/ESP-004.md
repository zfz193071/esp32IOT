# ESP-004 建立可重复构建与烧录工程

- 里程碑：M1
- 状态：进行中（通用参考目标编译通过，待实物板型确认与烧录验证）
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-003](ESP-003.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

建立后续固件开发的基础工程。

## 实现范围

- 采用架构约定的 Arduino-ESP32 与 C++，根据实物选择并锁定构建工具、核心版本和板型。
- 建立 firmware/src、config、web、test 目录及构建、烧录、串口命令。
- 提供 BoardProfile 与私有配置样例，忽略 Wi-Fi 凭据和构建产物；实际电机保持断开。

## 交付物

- 可构建的最小固件工程、依赖锁定信息、开发环境说明、忽略规则。

## 验收步骤与预期

- [ ] 从干净构建产物状态按文档编译成功，并在正确板型烧录。
- [ ] 串口可识别启动信息；错误或缺少板卡配置能明确报错。
- [ ] 配置样例和日志不含真实 Wi-Fi 密码。

## 前提与限制

本工单开始前确认本机串口权限及设备连接。
