# ESP-020 开放温控配置 API 与网页功能

- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

从手机查看温度、配置阈值并切换自动模式。

## 实现范围

- 实现 PUT /api/v1/config，两字段原子校验与持久化；成功返回快照。
- 存储失败返回 503 并保持旧配置；参数错误 400；自动模式不可用 409。
- 页面显示温度、样本健康、故障、阈值与手动／自动模式，提供配置提交与校验反馈。
- 复用单写请求和超时恢复机制，区分加载值、编辑值、已保存值。

## 交付物

- 温控 API、页面表单、错误响应与操作说明。

## 验收步骤与预期

- [ ] 正常修改阈值后自动控制按新值工作，重启后阈值保留。
- [ ] 非法配置或存储失败时页面不显示保存成功，设备保持旧配置。
- [ ] 传感器失效和恢复状态正确显示，恢复后仍需主动进入自动。
- [ ] 手动操作后页面同步显示 manual，不保留虚假 auto 状态。

## 前提与限制

全部 HTTP 写入口仍须满足 013 的同源与严格校验约定。
