## 目标

网页写入遵循统一控制规则。

## 实现范围

- 实现 PUT /api/v1/power 与 PUT /api/v1/mode，成功返回最新快照。
- 要求 application/json，严格检查类型、字段、枚举、缺失字段和非法请求体。
- 拒绝跨源写入，不启用开放 CORS；明确 Origin/Host 校验与无 Origin 的本地诊断请求策略。
- 无可用温度时自动模式返回 409；所有参数错误返回 400 且不改变状态。

## 交付物

- 写接口、错误码说明、正常和异常请求检查。

## 验收步骤与预期

- [x] 显式开／关可用，重复发送不会翻转；mode=manual 保持现有输出（真实 C++ 控制器主机验证）。
- [x] 非法类型、额外字段、缺失字段和不合法模式均不改状态（主机验证）。
- [ ] 非同源浏览器写请求不能操作设备，合法同源页面可操作。
- [x] 缺温度时 auto 请求返回 TEMPERATURE_UNAVAILABLE；GET 不执行写操作（主机验证）。

## 前提与限制

首版为可信局域网设计，跨源防护不等于用户身份认证。
