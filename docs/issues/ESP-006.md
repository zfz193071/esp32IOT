# ESP-006 实现统一命令、状态与手动控制器

- 里程碑：M2
- 状态：进行中（主机端手动控制器已实现，等待固件接入）
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-004](ESP-004.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

建立设备状态唯一来源。

## 实现范围

- 定义 DeviceState、命令来源、显式 SetPower 与 SetMode，预留架构规定的温度及阈值字段。
- 实现启动手动关闭、显式开关幂等、单按键在控制器内切换、多来源串行排序。
- 无温度能力时拒绝自动模式；控制器不依赖 HTTP、红外库或 GPIO。
- 明确 bootId/revision 的生成与变化规则，区分采样年龄随时间计算与业务状态版本。

## 交付物

- domain 模块、命令／状态说明和手动控制规则测试。

## 验收步骤与预期

- [x] 重复 SetPower(true) 始终开启，重复关闭始终关闭（主机测试）。
- [x] 按顺序输入不同来源命令，最后被接受的命令决定状态（主机测试）。
- [ ] 无温度时 SetMode(auto) 被拒绝且不改状态；每次重启手动关闭且 bootId 改变。
- [x] 无硬件依赖的测试可在电脑执行。
