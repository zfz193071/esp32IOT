# ESP-010 接入红外控制与重复帧过滤

- 里程碑：M3
- 状态：进行中：映射与重复帧过滤已实现，待真实解码接入
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-008](ESP-008.md)、[ESP-009](ESP-009.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

让红外与按键共享同一控制器。

## 实现范围

- 将已核对按键映射为显式开／关；如果遥控器只能采用切换键，明确记录映射。
- 过滤长按重复帧和无关地址／命令，不直接写电机 GPIO。
- 记录 infrared 命令来源，并验证与实体按键交替控制。

## 交付物

- 正式红外适配器、映射说明和遥控验收记录。

## 验收步骤与预期

- [ ] 短按指定开／关键，输出与 LED 同步；长按 3 秒不产生反复切换。
- [ ] 未知键不影响状态；按键和遥控器交替操作后结果一致。

## 前提与限制

此单完成 M3 遥控能力。

## 完成记录

2026-10-28：实现 `firmware/src/input/InfraredInput.*`，按协议、地址、命令精确映射开／关／切换，过滤重复帧、连续完整帧、未知键、过期和乱序帧。AppLoop 每轮最多读取一帧，经统一控制器记录 infrared 来源，最终统一提交风扇与 LED。

`sh firmware/test/run-host-tests.sh` 通过全部 C++ 测试与 14 项 Node 测试；模拟覆盖长按 3 秒、松开再按、计时回绕，以及按键／红外／网页交替和同轮处理。详见 [红外输入接入说明](../development/infrared-input.md)。

测试编码仅为合成数据，无正式遥控映射。ESP-009 的实测协议、地址、按键码和重复周期、具体接收器驱动及实物验收仍未完成，上述硬件验收项保持未勾选。

后续主机回归补充按键历史过期：长时间未接收红外后，旧时间戳不会让新按键永久被判为乱序；边界帧龄内的连续帧仍按捕获时间过滤。相关测试在 `InfraredInputTest.cpp`。
