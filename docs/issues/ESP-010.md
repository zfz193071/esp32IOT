# ESP-010 接入红外控制与重复帧过滤

- 里程碑：M3
- 状态：待办
- 范围：必需 · 局域网 MVP
- 依赖：[ESP-008](ESP-008.md)、[ESP-009](ESP-009.md)
- 架构依据：[系统架构](../architecture.md)、[硬件清单](../hardware.md)

## 目标

让红外与按键共享同一控制器。

## 实现范围

- 将已核对按键映射为显式开／关；如果遥控器只能采用切换键，明确记录映射。
- 过滤长按重复帧和无关地址／命令，不直接写电机 GPIO。
- 记录 infrared 命令来源，并验证与实体按键交替控制。

## 交付物

- 正式红外适配器、映射说明和遥控验收记录。

## 验收步骤与预期

- [ ] 短按指定开／关键，输出与 LED 同步；长按 3 秒不产生反复切换。
- [ ] 未知键不影响状态；按键和遥控器交替操作后结果一致。

## 前提与限制

此单完成 M3 遥控能力。
