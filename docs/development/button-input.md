# 按键消抖开发与验证

ESP-005 的硬件无关部分位于 `firmware/src/input/ButtonDebouncer.h` 和 `.cpp`。模块接收已转换为“是否按下”的输入和毫秒时间，每次调用立即返回，稳定按下时仅返回一次事件。GPIO 读取与 LED 驱动待 BoardProfile 确认后接入。

## 输入与事件约定

构造参数 `debounceMs` 是按下与释放共同使用的稳定时间，必须由调用者明确传入。测试使用 20 ms，仅用于验证边界，不是实测推荐值；0 表示不等待稳定时间，但仍只在按下边沿产生事件。

`update(pressed, nowMs)` 由单一主循环调用。输入改变时重新计时，保持相同输入达到稳定时间后才确认。确认按下返回一次 `true`，持续按住返回 `false`；释放也必须稳定后才能接受下一次按下。

上电时按住按键不会产生事件。必须先观察到稳定释放，再接受新的按下，避免启动时误开启输出。这是本次实现选用的启动规则，尚待实物验证。

`nowMs` 使用单调递增的 32 位无符号毫秒时钟，允许自然回绕，不允许人为倒退或把新启动的时钟传给旧实例。模块使用无符号时间差；稳定时间与观测间隔应小于半个时钟周期（2³¹ ms）。主循环仍须及时采样，软件无法识别两次采样之间未被观察到的短脉冲。

硬件适配器负责按 BoardProfile 的有效电平将 GPIO 转换为 `pressed`。收到事件后调用 `FanController::toggleFromButton()`，不在输入模块直接写风扇 GPIO。入门 LED 实验应单独装配，不能把本测试中的控制器输出断言解释为 LED 实测。

## 主机验证

```sh
sh firmware/test/run-host-tests.sh
```

统一入口同时执行手动控制器与按键消抖测试，使用 C++11 和严格编译警告。测试覆盖：

- 按下抖动重置计时，达到稳定时间的边界才触发。
- 持续按住 3 秒无重复事件，释放抖动不会重新使能。
- 启动按住及启动短暂释放不产生误事件。
- 32 位毫秒计数回绕、不均匀采样及零等待参数。
- 模拟连续按下释放 20 次，每次通过现有控制器恰好切换一次。
