# 手机控制页面与请求协调

ESP-014／015 已实现硬件无关的网页和请求协调逻辑，浏览器通过同源 API 操作控制器。设备 HTTP 服务、资源嵌入与实际手机联调仍依赖 ESP-004、012、013；当前的本机预览只操作模拟状态。

## 运行与测试

需要 Node.js；本轮使用 v22.19.0，无第三方依赖。

```sh
# 主机端控制器、消抖与网页请求测试
sh firmware/test/run-host-tests.sh

# 单独运行网页时序测试
node --test firmware/test/WebClientTest.mjs

# 启动模拟设备，保持进程运行，Ctrl+C 停止
node firmware/tools/preview-server.mjs
```

打开 `http://127.0.0.1:8312`。预览页明确显示“模拟设备预览”，开关不影响实际风扇。服务器仅监听本机；端口占用时可通过 `ESP32_PREVIEW_PORT` 指定其他端口。不要将预览服务器当作 ESP32 服务或局域网设备部署。

## 文件与设备接口

| 文件 | 职责 |
|---|---|
| `firmware/web/index.html` | 中文手机页面、显式开关、模式与状态展示 |
| `firmware/web/style.css` | 自适应布局、触控按钮、焦点样式 |
| `firmware/web/app.mjs` | DOM 更新、每秒轮询与点击绑定 |
| `firmware/web/client.mjs` | 状态校验、写入互斥、超时与旧响应隔离 |
| `firmware/web/config.mjs` | 阈值校验、独立编辑草稿与确认 |
| `firmware/tools/preview-server.mjs` | 本机开发模拟器；不进入固件资源 |

页面使用 `/api/v1/state`、`/api/v1/power`、`/api/v1/mode`、`/api/v1/config`，遵循架构的 JSON 字段与错误约定。无外部字体、CDN 或网络资源。模拟器只支持手动模式和内存阈值保存，没有真实 Wi-Fi、GPIO、红外或温度采集。新增表单与故障验证见 [网页温控配置与模拟接口](web-temperature-config.md)。

后续固件需嵌入并提供五个 web 文件：`/` 为 `text/html`，`/style.css` 为 `text/css`，`/app.mjs`、`/client.mjs` 和 `/config.mjs` 为 `text/javascript`。构建工具未锁定，因此嵌入生成脚本及 ESP32 路由装配尚未实现。模拟标记仅由开发服务器的 `X-ESP32-Simulator: true` 响应头启用，固件不发送该标记。

## 请求与显示规则

- 同时最多一个写请求，不排队或自动重放点击；提交后继续锁定操作直到状态查询结束。
- 按钮发送显式 `on: true/false`。等待响应时保留旧值并显示“等待同步确认”，不乐观显示成功。
- 写入开始时使此前的轮询请求失效；晚到的旧响应或错误都不能覆盖当前状态。
- 同一 bootId 只接受不低于当前 revision 的状态；相同 revision 仍可刷新采样年龄。已退出的 bootId 不再接受。
- 写响应跨越重启时不据此显示命令成功，重新查询当前启动状态；命令不重发。
- 请求含 JSON 解析最多等待 4 秒，超时中止请求并隔离晚到响应。写超时显示结果未知，随后只查询状态。
- 每秒尝试轮询，已有读取或写入时跳过该轮。失联显示最后同步时间与历史状态，并禁用写操作；恢复查询成功后再开放操作。
- 无有效温度或样本超过 5 秒时禁用自动按钮，设备仍须自行验证自动模式准入。
- JavaScript 客户端拒绝超出安全整数范围的 revision，避免数值精度导致误排序。设备序列化须遵守此边界，或后续统一调整接口表示，不能静默截断 64 位值。

## 验证记录

2026-10-28：7 组 Node 测试通过，覆盖快速连续操作、旧轮询晚到、跨重启写响应、旧 bootId、写入生效但响应丢失、无效状态、版本倒退、自动模式拒绝和安全整数边界。

Chrome 后台以 390×844 手机视口验证：页面无横向溢出；开、关、手动保持输出正常；自动模式在无温度时禁用；模拟标记可见；资源全部同源。模拟离线后操作禁用且提示历史状态，恢复网络后查询恢复，未自动发送写命令。

上述验证针对本机模拟器，不替代 ESP32 编译、资源嵌入、真实手机访问、实体按键／红外同步和设备重启验收。
