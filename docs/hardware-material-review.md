## 例程引脚是逐项实验接线，不是整机引脚表

| 实验 | 接线示例 | 整机冲突 |
|---|---|---|
| 直流电机 | `IN1 → GPIO15` | 与普通 LED D1 的 GPIO15 冲突 |
| 普通 LED D1 | `D1 → GPIO15` | 与电机示例冲突 |
| 按键 K1～K4 | `GPIO14、27、26、25` | K1 的 GPIO14 与红外示例冲突 |
| 红外接收 | `IR → GPIO14` | 与 K1 示例冲突 |
| DS18B20 | `DS → GPIO13` | 暂未发现上述示例冲突 |

底板原理图显示外设信号通过端子引出，连接哪个 ESP32 GPIO 取决于实际杜邦线。因此以上数字只能用于可复现的单项实验或候选整机接线。`firmware/src/board/BoardProfile.*` 现提供经典 ESP32 候选配置校验：未分配、保留／Flash 引脚、输出接到仅输入引脚、风扇控制接启动配置引脚、信号复用冲突均拒绝；M4 可以不配置温度，M5 必须配置。`firmware/src/board/BoardIoAdapter.*` 通过该配置规范化按键电平，先初始化风扇为关闭电平，再初始化 LED 与按键；配置无效时不触碰 GPIO。实际 GPIO 实现仍须保证在启用输出时不会产生反向脉冲。上述代码不提供默认电机 GPIO，也不证明电气负载、接线或复位安全。

## 现在可以继续开发

- ESP-003：BoardProfile 规格、候选接线方案与冲突检查；最终 GPIO 表须与实际接线核对。
- ESP-004：Arduino-ESP32 最小构建、启动入口和串口诊断；实际板型、工具链和烧录命令仍需设备验证。
- ESP-005、008：按键、LED 的 GPIO 适配及电机断开情况下的入门实验。
- ESP-009～011：红外接收诊断、候选库适配、实际 Wi-Fi 端口；正式遥控映射待实测。
- ESP-012～016、020：将已有状态／写接口、网页与请求协调接入真实 HTTP 服务；教程 WebServer 例程的连接等待循环不能直接用于本项目主循环。
- ESP-017～019：非阻塞温度驱动、配置持久化适配和自动温控装配；Arduino 温度例程明确使用默认阻塞式转换，不可直接放入主循环。
- ESP-007：可写可配置 FanOutput 和关闭初始化的软件适配；连接电机之前须完成 ESP-002 的供电、负载和复位关闭验证。

各项板端实现和验收仍按对应工单记录。资料改善了开发依据，不等于已烧录、已接线或已通过整机验收。
