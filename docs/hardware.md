# 硬件核对（M0）

依据图片：桌面「个人间流/esp32.png」中的 ESP32 升级版套件。商品图不能替代实物清单、底板原理图或接线说明。

| 项目 | 当前信息 | 开始接线前需确认 |
|---|---|---|
| ESP32 主控 | 商品图标注 ESP32 | 模组完整型号、板型、USB 转串口芯片及烧录方式 |
| 扩展底板 | 可见按键、LED、数码管、蜂鸣器和继电器 | 原理图、跳线状态、已占用 GPIO、上电默认电平 |
| 电机和扇叶 | 商品图包含直流电机 | 额定电压、启动／堵转电流、固定方法 |
| 电机驱动 | 尚未确认 | 是否板载、型号、允许负载、控制接口、续流保护 |
| 供电 | 配套 Type-C 线 | 电源能力、电机供电路径、是否需独立电源及共地方式 |
| 红外 | 有遥控器 | 是否含接收器、接收器电压与引脚、遥控器电池 |
| 温度 | 标注 18B20 | 实际型号、引脚顺序、上拉电阻与底板是否适配 |
| 其他模块 | 图中有多种传感器 | 暂不纳入 MVP 接线 |

| TEMPERATURE_DATA | 待确认 | 待确认 | 待确认 | 待补 | 未验证 |

必须核对启动相关引脚、仅输入引脚、底板复用冲突以及逻辑电平兼容性。没有核对资料之前不提供猜测 GPIO，不把电机直接接到 GPIO，不将继电器等同于已验证的电机驱动。

先验证 LED 和输入，再连接驱动和电机。上电默认关闭不仅是软件行为，还需要核对驱动输入在复位和烧录期间的硬件状态。
